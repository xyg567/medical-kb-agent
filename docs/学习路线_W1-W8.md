# 学习路线（W1–W8）

定位：医学科研智能体 → 医疗问答（知识库）子方向。

## 分岔点

- **第 1 周（11/5–11/8）**：全员相同，环境 + 模块零 + 最小 Agent demo
- **第 2 周起（11/9–）**：四个子方向分开
- **第 9 周起（1 月）**：四模块联调成统一平台

## 第 1 周：共享基础

| 模块 | 内容 |
|---|---|
| 科研流程 | 选题 → 文献 → 设计 → 收数据 → 统计 → 图表 → 论文 |
| Agent | 规划 + 工具 + 记忆 + 反思 |
| LLM | Prompt、JSON 输出、Function Calling、RAG 概念 |
| 工程 | conda、Git、API Key、目录规范 |
| 产出 | 带工具调用的最小 Agent demo |

## 第 2–8 周：医疗问答专项

| 周次 | 学习主题 | 动手产出 | 验收 |
|---|---|---|---|
| W2 11/9–11/15 | RAG 全链路：切分/embedding/向量库/top-k/prompt | 不用框架手写 100 行：3 篇文档→入库→检索→带出处回答 | 能说出“这段来自哪个文件” |
| W3 11/16–11/22 | 医学数据来源与清洗、元数据设计 | 选一个病种（肝癌/乳腺癌），10–20 份指南/说明书，转 txt/md | ≥500 chunk，可溯源 |
| W4 11/23–11/29 | 检索优化：chunk 大小、混合检索、rerank | 3 组参数对比 + BM25 + bge-reranker | Recall@5 有提升，有对比表 |
| W5 11/30–12/6 | 问答质量：引用、拒答、多轮 | 引用精确到页码；低相似度拒答；追问改写 | 问资料外的病能说“未提及” |
| W6 12/7–12/13 | 评测方法 | 30–50 条 QA（含 10 条资料外），算召回率/引用准确率/拒答率 | 一份评测报告 |
| W7 12/14–12/20 | 工程化 | `/api/ask` + Gradio 或简单页面 | 别人能调通拿到 JSON |
| W8 12/21–12/27 | 文档与演示 | README、接口文档、3 分钟视频 | 队友能复现 |

## 统一接口（提前定）

```json
{
  "question": "肝癌介入治疗的适应症？",
  "answer": "……[1][2]",
  "citations": [{"doc": "CSCO肝癌指南2024", "page": 12, "chunk_id": "csco#37"}],
  "refused": false,
  "confidence": 0.82
}
```

## 每周固定动作

- 周日：Word 周报发小群（学习内容 / 进展 / 问题 / 下周计划，配图）
- 平时：卡住立刻群里问
- 每 2–3 周：师生组会，5 分钟口头汇报
- 每周至少一次 commit

## 技术选型

| 用途 | 选型 |
|---|---|
| 大模型 | DeepSeek（OpenAI 兼容） |
| Embedding | `BAAI/bge-small-zh-v1.5`（本地，免费） |
| 向量库 | Chroma |
| 后端 | FastAPI |
| 评测 | 自建脚本 / RAGAS |

> 注意：DeepSeek 没有 embedding 接口，向量化必须用本地模型。
