# CSCO 原发性肝癌诊疗指南（节选·演示用）

【来源说明】本文档为本地演示语料，仅用于第一周"本地文档检索"工具的验收测试，内容为指南常见公开结论的节选复述，不构成诊疗依据。

## 介入治疗（TACE）适应症

肝动脉化疗栓塞术（TACE）适用于：肿瘤多发、最大直径不超过 7cm 的 BCLC-B 期（中期）肝癌病人，或者局限于肝内、负荷可控，同时肝功能 Child-Pugh 评分 A 或 B 级的病人。要求肿瘤供血动脉通畅、门静脉主干无完全闭塞。

## 介入治疗的相对禁忌

Child-Pugh C 级、肝功能失代偿、门静脉主干完全癌栓、远处转移、肾功能障碍或大量腹水的病人，一般不宜首选 TACE，应考虑系统治疗或其他方案，由多学科会诊（MDT）决定。

## 系统治疗

对于晚期（BCLC-C 期）肝癌病人，一线系统治疗包括阿替利珠单抗联合贝伐珠单抗（T+A 方案）或多纳非尼、仑伐替尼、索拉非尼等靶向药物。免疫联合方案需评估乙肝病毒再激活风险，用药期间监测肝功能。

## 随访

根治性治疗后 2 年内每 3 个月复查一次甲胎蛋白（AFP）与肝脏超声或增强影像，2 年后可延长至每 6 个月。规律复查是发现早期复发、保留再治疗机会的关键。
